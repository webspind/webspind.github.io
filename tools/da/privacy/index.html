Privatliv

Webspinds værktøjer kører i din browser. Den lyd, video og de billeder, du vælger, bliver åbnet og behandlet på din egen enhed. De bliver ikke uploadet, gemt eller set af nogen.

Det henter din browser

  • Siderne og den kode, der gør arbejdet, kommer fra webspind.com, som ligger på GitHub Pages. Som ved alle hjemmesider får GitHub de almindelige tekniske oplysninger (fx din IP-adresse), når din browser beder om en side. Dem får vi ikke.
  • To værktøjer bruger en AI-model: Transskription og Fjern baggrund. Hver af dem henter sin model, ikke dine filer, første gang du bruger det, fra den offentlige modeltjeneste Hugging Face. Din browser gemmer modellen i sin cache, så den ikke skal hentes igen næste gang.

Det gør vi ikke

  • Ingen cookies, ingen statistik, ingen sporing og ingen reklamer.
  • Ingen konti og ingen tilmelding.
  • Intet af det, du behandler, bliver sendt til os eller andre.

Det bliver på din enhed

Modellerne og programfilerne ligger i din browsers almindelige cache, så værktøjerne starter hurtigere næste gang. Du fjerner dem ved at rydde sidens data i browserens indstillinger. Dine egne filer findes kun i fanens hukommelse, mens du bruger værktøjet, og er væk, når du trykker Start forfra eller lukker fanen.

De open source-dele, vi bruger, og deres licenser står i LICENSES.md. Spørgsmål? Skriv til webspind@gmail.com.
