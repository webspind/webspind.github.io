Seitenzahlen in eine PDF einfügen

Setze Seitenzahlen auf jede Seite, genau dort, wo du sie haben willst.

Wird auf deinem Gerät verarbeitet. Nichts wird hochgeladen.

So funktioniert's

  1. Füge eine PDF hinzu.
  2. Wähle Position, Startnummer und Format.
  3. Klicke auf Starten und lade die nummerierte PDF herunter.

Häufige Fragen

Kann ich das Deckblatt auslassen?

Ja. Setze den Haken bei Erste Seite auslassen, dann beginnt die Nummerierung auf Seite zwei.

Werden meine Dateien irgendwo hochgeladen?

Nein. Die Seite lädt die Tools in deinen Browser, und deine Dateien werden auf deinem eigenen Gerät geöffnet und gespeichert. Sobald die Seite geladen ist, kannst du die Internetverbindung trennen, und die Tools funktionieren weiter.

Gibt es eine Größenbeschränkung für Dateien?

Nur den Arbeitsspeicher deines Geräts. Die meisten Computer schaffen PDFs mit mehreren hundert Seiten. Auf dem Handy können sehr große Dateien langsam sein.

Ist das wirklich kostenlos?

Ja. Es gibt kein Konto, keine Testphase und kein Wasserzeichen.
