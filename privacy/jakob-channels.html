Privacy Policy

jakob-channels · last updated 15 October 2026

jakob-channels is a private tool used only by its owner, Jakob Munch-Brandt, to manage his own YouTube channels (Scribbled Explains, Outnumbered and Dreadox). It is not offered to anyone else.

What data it uses

When the owner signs in with Google, the tool requests access to the YouTube Data API and YouTube Analytics API for his own channels. It reads and updates:

  • video details on his channels: titles, descriptions, tags, thumbnails, captions, playlists, publish times and privacy settings;
  • comments on his videos (to post and read the channel's own comments);
  • his channels' analytics: views, watch time, audience retention and similar reports;
  • public data about other channels' videos (titles, view counts, subscriber counts) for topic research.

How the data is used

Only to publish and manage the owner's own videos and to analyse how they perform. The data is not sold, shared with third parties, used for advertising, or used to train machine-learning models.

Where it is stored

Access tokens and downloaded reports are stored only on the owner's own computer. Nothing is stored on any server operated by this tool.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local token files removes all stored access.

Google API Services

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.
