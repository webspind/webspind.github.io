Privatliv

Én politik pr. app, som Apple kræver det. Fælles for dem alle: ingen reklamer, ingen analyse og ingen server hos mig.

Wakebird: Birdsong Alarm Clock Dine alarmer ligger kun på din iPhone. Ingen konto, ingen analyse. Købet bekræftes via RevenueCat. Læs politikken → Friendloop: Stay in Touch Dine venner, noter og påmindelser bliver på din iPhone. Ingen konto, ingen analyse. Køb bekræftes via RevenueCat. Læs politikken → Supersub: Offline Football Din klub bor på din iPhone. Ingen konto, ingen reklamer, ingen analyse. Køb bekræftes via RevenueCat. (Politikken er på engelsk.) Læs politikken → Longwalk: Walk the Camino Dine gåture bliver på din iPhone, og sundhedsdata forlader den aldrig. Kortfliser kommer fra OpenFreeMap; køb bekræftes via RevenueCat. Læs politikken → Jagtprøven – Jagttegn & Teori Dine svar ligger på din enhed og i din egen iCloud. Ingen konto, ingen analyse. Køb bekræftes via RevenueCat. Læs politikken → Cookside: Recipe Cook Mode Dine opskrifter ligger på din iPhone og i din egen iCloud. Ingen konto, ingen analyse. Køb bekræftes via RevenueCat. Læs politikken → Handhold: Daily Habit Coach Dine vaner ligger på din iPhone og i din egen iCloud. Ingen konto, ingen analyse. Køb bekræftes via RevenueCat. (Engelsk) Læs politikken → Loftpass: Part 107 Test Prep Dine svar ligger på din iPhone og i din egen iCloud. Ingen konto, ingen analyse. Køb bekræftes via RevenueCat. (Engelsk) Læs politikken → Fortøy: Båtførerprøven Svarene dine ligger på iPhonen og i din egen iCloud. Ingen konto, ingen analyse. Kjøp bekreftes via RevenueCat. (Norsk) Læs politikken → Wendemarke: Bootsprüfung A+D Antworten bleiben auf dem iPhone und in deiner eigenen iCloud. Kein Konto, keine Analyse. Käufe via RevenueCat. (Tysk) Læs politikken →
